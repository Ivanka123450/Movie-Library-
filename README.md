## Описание программы

**Movie Library** — это простое GUI-приложение для ведения личной коллекции фильмов. Приложение позволяет добавлять фильмы, фильтровать их по жанру и году выпуска, а также сохранять и загружать данные в формате JSON.

### Возможности:
- ✅ Добавление фильмов с указанием названия, жанра, года выпуска и рейтинга
- ✅ Фильтрация фильмов по жанру (Драма, Комедия, Боевик, Фантастика, и др.)
- ✅ Фильтрация по году выпуска (точное совпадение)
- ✅ Сохранение данных в JSON-файл (автоматически)
- ✅ Загрузка данных из JSON-файла (при запуске)
- ✅ Валидация вводимых данных (проверка года и рейтинга)
- ✅ Сброс фильтров одной кнопкой

## Инструкция по запуску

### Требования:
- Python 3.6 или выше
- Библиотека Tkinter (обычно идёт в комплекте с Python)

### Запуск:
1. Откройте терминал или командную строку
2. Перейдите в директорию проекта:
   ```bash
   cd movie-library
Запустите приложение:

bash
python movie_library.py
Примеры использования
Добавление фильма:
Заполните все поля формы:

Название: "Побег из Шоушенка"

Жанр: Выберите из списка (например, "Драма")

Год выпуска: 1994

Рейтинг (0-10): 9.3

Нажмите кнопку "Добавить"

Фильм появится в таблице внизу окна

Фильтрация:
По жанру: Выберите жанр из выпадающего списка в разделе "Фильтрация" и нажмите "Применить"

По году: Введите год в поле "Год:" и нажмите "Применить"

Можно комбинировать оба фильтра одновременно

Для сброса нажмите "Сброс" — отобразятся все фильмы

Сохранение и загрузка:
Данные сохраняются автоматически в файл movies.json при каждом добавлении фильма

При запуске программы данные автоматически загружаются из movies.json

Файл movies.json создаётся в той же папке, что и программа

Тестовые данные (примеры для проверки):

Валидация данных
Приложение проверяет:

Поле	Правило	Пример ошибки
Название	Не должно быть пустым	"Ошибка: Название и жанр обязательны"
Жанр	Не должен быть пустым	"Ошибка: Название и жанр обязательны"
Год	Целое число от 1888 до 2100	"Ошибка: Год должен быть целым числом"
Рейтинг	Число от 0 до 10	"Ошибка: Рейтинг должен быть числом от 0 до 10"
Примеры некорректного ввода:

Год: abc => ❌ ошибка

Год: -500 => ❌ ошибка

Рейтинг: 15 => ❌ ошибка

Рейтинг: -3 => ❌ ошибка

Пустое название => ❌ ошибка
